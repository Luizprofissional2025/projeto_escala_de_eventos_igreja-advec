# ⛪ Escala de Eventos Para Voluntarios — Igreja ADVEC

> 🚧 **Projeto em desenvolvimento**

Aplicação web desenvolvida com **React** para organização e apresentação de eventos, cultos e escalas da Igreja ADVEC.

O projeto faz parte da minha jornada de aprendizado em **Desenvolvimento Front-end**, colocando em prática conceitos de componentização, roteamento, gerenciamento de estado e responsividade.

## 📸 Preview

![GitHub_Perfil](./preview.png)

## ✨ Funcionalidades

* 🏠 Página inicial com apresentação de conferências;
* 🧭 Navegação entre páginas;
* 📋 Cadastro inicial de disponibilidade para escala;
* 📝 Entrada de nome e seleção de culto;
* 🗑️ Limpeza dos dados da escala;
* 📱 Estrutura responsiva e interativa.

> Algumas funcionalidades ainda estão em desenvolvimento.

## 🚀 Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/Luizprofissional2025/projeto_escala_de_eventos_igreja-advec.git
```

### 2. Entre na pasta do projeto

```bash
cd projeto_escala_de_eventos_igreja-advec
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute o projeto

```bash
npm run build
```

Após executar, o Vite disponibilizará o endereço local no terminal.

### Build de produção

```bash
npm run build
```
